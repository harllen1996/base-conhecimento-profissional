# Glossário Operacional

## Siglas e termos

| Sigla | Significado |
|-------|------------|
| **AWB** | Air Waybill — etiqueta de rastreamento do pacote |
| **BR** | Business Record — registro de um pacote/pedido no sistema |
| **CB** | Cross-Border — pacotes internacionais |
| **EHA** | Exception Handling Area — área de tratamento de exceções |
| **ETA** | Estimated Time of Arrival — prazo previsto |
| **FMH** | First Mile Hub |
| **FTE** | Full-Time Equivalent — equivalência de funcionário integral |
| **FWD** | Forward — fluxo de entrega (ida) |
| **HD** | Home Delivery |
| **KPI** | Key Performance Indicator |
| **LMH** | Last Mile Hub |
| **OTP** | One-Time Password — código de confirmação |
| **PIC** | Person in Charge — responsável pelo projeto |
| **PMO** | Project Management Office |
| **POP** | Product/Operations Process — portal de submissão de demandas para Produto |
| **RR** | Reroute — redirecionamento de rota |
| **RTS** | Return to Seller — devolução ao vendedor |
| **SIP** | Seller In-Platform (vendedor dentro da plataforma) |
| **SOC** | Sorting & Operations Center — centro de operações |
| **SPX** | Shopee Express — braço logístico da Shopee |
| **TO** | Transfer Order — ordem de transferência entre centros |
| **WBR** | Weekly Business Review — reunião semanal de negócios |
| **XD** | Cross-Dock — transferência sem armazenagem |
| **3PL** | Third-Party Logistics — parceiro logístico terceirizado |

| **Zebra** | Impressora portátil de etiquetas térmicas |
| **Turtle** | Sistema web de fila de impressões |
| **Spark** | Sistema de integração com cubadores |
